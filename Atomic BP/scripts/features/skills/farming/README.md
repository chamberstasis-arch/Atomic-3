Farming tendrá su propia fortuna y su propio bono de XP, pero además agrega una estadistica adicional llamada "Mutación Activa"; esta estadistica funcionará por porcentajes, del 0% al 100%, en el scoreboard se reflejaria como del 1-1000 siendo 502 = 50.2% para incluir decimales
¿Que hace mutación activa?
Por cada "crop" valido (Que sea algo relacionado a la skill de farming) se aplique este porcentaje y si "atina" entonces se daría un drop especial unico de cada bloque

Por ejemplo puede que la "mutación" de la zanahoria sea "Zanahoria mutada" y si el jugador tiene 100% de mutación activa le de, lo que corresponda de zanahorias + la zanahoria mutada
